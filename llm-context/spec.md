Assignment description
Group members: maximum of four members per group.
Objective:
Develop a mobile/web application for an organization of your choice to enhance information security policy awareness and management among employees of a real-world organization. The application will be designed to educate employees on security best practices, manage policy compliance, and monitor security-related activities.
Assignment Overview:
This assignment involves creating a mobile/web application aimed at improving the organization's information security posture. The application will provide educational resources, facilitate policy management, and track compliance with security protocols.
Part 1: Product Proposal
- A detailed project proposal outlining the scope, objectives, and deliverables.
- Detailed functional and non-functional requirements.
- Mobile/web application architecture
- Detailed design of key modules and components including details of the implementation of core features (User authentication and authorization, Policy management module and Security training and awareness module, Compliance tracking and reporting and Development of a user-friendly interfaces)
Part 2: Product Development and demonstration
- The application should be developed using a modern mobile/web development framework based on the approved proposal in part 1.
- The backend should be secure and scalable.
- The application should follow secure coding practices and be regularly updated to address new security threats.
- Development will be evaluated based on the product demonstration conducted by the group.
- The Acceptable use policy needs to be created based on the application developed which needs to be submitted day before the product demonstration.
